# Chatters 使用说明（v1 Windows）

> 适用版本：0.1.0　平台：Windows 10/11 x64　日期：2026-10-28

## 1. 安装与启动

- **安装包**：运行 `Chatters_0.1.0_x64-setup.exe`（NSIS），按向导安装后从开始菜单启动。
- **免安装**：直接运行 `chatters.exe`（同一目录下的 `WebView2Loader.dll` 等运行时文件需一并保留）。
  请把整个文件夹放在固定位置后再创建桌面快捷方式。
- 系统要求：Windows 10/11 x64，系统需安装 WebView2（Win11 自带；Win10 若缺失，安装包会引导安装）。

## 2. 首次运行：放行防火墙

启动后 Windows 会弹出「Windows 安全警报」，请勾选 **专用网络** 并允许，否则设备发现与连接会被拦截。

若已误点取消：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 找到 Chatters（或手动放行
**UDP 28100**、**TCP 28101** 入站）。

## 3. 连接另一台设备

1. 两台电脑连同一局域网（同一路由器/交换机，同一网段）。
2. 都启动 Chatters，几秒内即可在「设备」页看到对方昵称（如 `PC-8f3a`）。
3. 看不到对方时：
   - 确认没开 **访客网络 / AP 隔离**；
   - 检查防火墙是否放行（见上）；
   - 确认两台机器的「发现端口」一致（设置页，默认 28100）；
   - 仍看不到时，在设备页输入对方 IP（如 `192.168.1.10` 或 `192.168.1.10:28101`）点「添加设备」，
     程序会直接握手建连并把对方加入列表（F3，多网卡/AP 隔离场景的兜底）。

## 4. 发送与接收

| 内容 | 操作 | 接收方行为 |
|---|---|---|
| 文字 | 点设备「开始聊天」→ 输入 → 发送（Ctrl+Enter 也可） | 自动接收；气泡显示「已送达」 |
| 图片 | 会话页「发送图片」，或 **直接 Ctrl+V 粘贴截图**，或**拖拽图片到窗口** | **自动接收**，完成后直接在会话中预览 |
| 文件 | 会话页「发送文件」，或**拖拽文件到窗口** | 默认弹出「等待确认」卡片，点「接受」后开始接收 |

- 拖入**文件夹**时不会发送，界面提示"请将文件夹压缩为 zip 后发送"（F31）。
- 粘贴的是图片时自动转成临时文件发送（F21）；粘贴文字仍按普通文本输入处理。

- 传输卡片显示进度百分比、速度与剩余时间；可随时「取消」。
- 断网/对端关闭后任务会变为「失败（连接已断开，可重试）」，点「重试」会**从已收字节继续**（简版续传）。
- 接收文件保存到 `%USERPROFILE%\Downloads\Chatters`（可在设置页修改）；同名文件自动加 `(1)` 后缀，不覆盖。
- 传输完成后自动校验 sha256，不一致会标记失败并删除残留临时文件。

## 5. 设置

「设置」页可修改：设备昵称、下载目录、发现端口（UDP）、通信端口（TCP）、主题（浅色/深色）、
自动接收图片、自动接收文件、开机自启，并可「清空全部历史」。

- 下载目录与自动接收设置**保存后立即生效**；
- 昵称与端口改动需要**重启应用**后生效；
- 两端「发现端口」必须一致，通信端口两端可以不同（通过发现包自动交换）。

## 6. 历史

- 消息与传输记录保存在 `%APPDATA%\com.chatters.app\history.json`，重启后打开会话自动载入。
- 会话页右上「清空本会话记录」只清空与该设备的记录；设置页「清空全部历史」清空全部记录。
- 设置页可勾选「清空历史时同时删除已接收文件」：**只删除下载目录内、由本应用记录的接收文件**，
  下载目录以外的文件不会被删除。
- 已接收完成的图片/文件在会话卡片上可直接「打开文件」「打开所在文件夹」「另存为」。

## 7. 托盘、通知与关闭行为

- 托盘图标右键菜单：显示主窗口 / 退出。
- **关闭窗口不会退出程序**，而是最小化到托盘（任务栏图标消失），再次双击程序会重新显示已有窗口（单实例）。
- 真正退出：托盘菜单「退出」。
- 窗口不在前台时：收到新消息、收到待确认文件、文件接收完成都会弹出系统通知（通知只提示事件类型，不含文件名与内容）。

## 8. 数据位置一览

| 内容 | 路径 |
|---|---|
| 配置 | `%APPDATA%\com.chatters.app\config.json` |
| 历史 | `%APPDATA%\com.chatters.app\history.json` |
| 接收文件 | `%USERPROFILE%\Downloads\Chatters`（默认） |
| 续传临时文件 | `<下载目录>\.chatters-partial\` |

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 列表一直为空 | 检查防火墙、是否为同一网段、是否开了 AP 隔离；确认两端口未被其他程序占用 |
| 发送失败（对端无响应） | 对端可能已退出或断网；确认对端在线后点「重试」 |
| 提示端口占用/无法监听 | 设置页换一个端口（两端发现端口需一致），重启应用 |
| 图片不显示预览 | 超过 8MB 的图片不内联预览（文件已正常接收，可在下载目录查看） |
| 杀毒软件拦截 | 将安装目录加入白名单（程序仅监听局域网端口，无外网连接） |
