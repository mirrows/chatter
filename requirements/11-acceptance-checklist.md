> 适用：Windows 10/11 x64、Android arm64　前置：两台同网段设备（或物理机 + 桥接虚拟机）

## B. 功能验收（按需求编号）

| 编号 | 用例 | 期望结果 | 结果 |
|---|---|---|---|
| F1 | 两端启动，同一局域网 | 3 秒内互相出现在设备列表 | ✅ |
| F2 | 设置页改昵称并重启 | 对端显示新昵称；`device_id` 不变 | ✅ |
| F3 | 设备页输入对方 IP（`ip` 或 `ip:端口`）点「添加设备」 | 立即建立会话并出现在列表；非法 IP 有错误提示 | ✅ |
| F4 | 关闭/启动对端 | 列表 45 秒内移除/恢复；页面顶部显示「已上线/已下线」提示 | ✅ |
| F10/F13 | 发送多行文字 + emoji | 内容一致，支持换行 | ✅ |
| F11 | 观察消息状态 | 发送中 → 已送达；对端离线时 → 发送失败并可「重发」 | ✅ |
| F12 | 点击消息气泡「复制」 | 剪贴板得到该消息全文，提示「已复制」 | ✅ |
| F20 | 「发送图片」选择本地图片 | 对端自动接收并显示预览 | ✅ |
| F21 | 截图后 Ctrl+V | 图片直接发送（纯文本粘贴仍进入输入框） | ✅ |
| F22 | 拖拽图片/文件到会话 | 直接开始传输 | ✅ |
| F23 | 接收完成后点「打开文件 / 打开所在文件夹 / 另存为」 | 分别用默认程序打开、资源管理器定位、复制到所选路径 | ✅ |
| F24 | 发送 5MB / 15MB / 25MB 图片 | 5/15MB 有预览；25MB 传输成功但提示预览不可用 | ✅ |
| F30/F31 | 拖入文件夹 | 不发送，提示「请将文件夹压缩为 zip 后发送」 | ✅ |
| F32 | 传输中断后重试 | 从已收字节继续（状态由「失败」→ 重试 → 完成） | ✅ |
| F33 | 传输过程 | 显示进度、速度、剩余时间；可取消；双方状态变「已取消」 | ✅ |
| F34 | 接收普通文件 | 默认弹「等待确认」；接受后开始；拒绝后双方「已拒绝」 | ✅ |
| F35 | 发送 1GB 以上文件 | 完成且内存不随文件大小线性增长；记录耗时与速率 | ✅（实测 ≤1GB；10GB 长稳见 `17`） |
| F36 | 校验一致性 | 完成即校验通过；人为篡改应失败（自动化已覆盖） | ✅ |
| F37 | 仅一对一 | 不存在群发入口 | ✅ |
| F40 | 打开会话查看历史；「清空本会话记录」 | 历史重启后仍可见；清空只影响该设备 | ✅ |
| F41 | 设置页勾选「同时删除已接收文件」后清空历史 | 下载目录内记录文件被删除，目录外文件保留 | ✅ |
| F42 | 同时与两台设备聊天 | 各自消息独立；未读数量显示在设备列表 | ✅ |
| F50 | 设置页开启开机自启 | 重新登录后自动启动（注册表项存在） | ✅ |
| F51 | 关闭窗口 | 最小化到托盘不退出；托盘「退出」真正退出；后台收消息有通知 | ✅ |
| F52 | 设置项保存 | 下载目录/自动接收即时生效；昵称/端口提示需重启 | ✅ |
| F53 | 文案 | 全中文，无硬编码遗漏（抽查） | ✅ |

> 2026-11-14 复验：以上功能项在 Windows 10/11 与 Android arm64 真机通过；
> 移动端差异项（私有下载目录 + 「另存为」导出、定时清理、无「打开所在文件夹」）已在 `16-v3-plan.md` I6.x 记录。
